# Challenge: Heat Pump Ready? (nuuEnergy)

Track: Buildings & Everyday Energy · Partner: nuuEnergy
Source: https://sun-weather-eb6.notion.site/Heat-Pump-Ready-nuuEnergy-Challenge-3fe93c43cade81af8b18f8d2e3778642

## Brief
Build an AI tool that gives a homeowner an honest first heat-pump-readiness assessment
in under three minutes, from data they already have (energy bill, building age, heating
system, address, a few photos). Give a transparent first answer and clearly flag what a
professional technician still needs to check.

| | |
|---|---|
| Goal | First readiness assessment in < 3 min |
| Inputs | Energy bill, building age, address, photos |
| Output | Green / yellow / red + short reason |
| Data | 5 buildings (3 dev, 2 eval) as CSV + JSON |
| Prototype | Runs locally in a standard browser |
| Top criteria | Technical execution (25) · Problem-solution fit & user value (25) |
| Prize | €1,000 + table football + Tech Day with nuuEnergy product team |

**Honesty over precision:** "I cannot tell from this data, a technician must check X and Y"
beats a confident wrong number.
