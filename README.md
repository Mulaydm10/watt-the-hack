# WATT THE HACK: Energy & AI Hackathon

Munich Climate Week, 2026-10-24, 09:00-19:00 CEST, Audimax Muenchen. One-day build.
Sponsor challenge: nuu energy or Ecurious (TBC).

## Repo map
- `notes/challenge.md` - the sponsor brief (fill in first)
- `notes/workflow.md` - append-only timestamped work log
- `notes/ai_onboarding_prompt.md` - paste-ready prompt for any AI agent
- `src/` - the solution code
- `data/` - datasets (gitignored)
- `submissions/` - final deliverables, pitch, demo
- `docs/` - pitch outline and extras

## Quickstart
1. Fill `notes/challenge.md`.
2. Build in `src/`; log progress in `notes/workflow.md`.
3. Commit small and often; push to `main`.
